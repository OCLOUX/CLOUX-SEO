Audit SEO multi-domaines, Schema.org JSON-LD, GEO/AEO (llms.txt, robots.txt agents IA), E-E-A-T, scoring et exports.

== Description ==

CLOUX SEO regroupe les briques SEO essentielles en une extension unique :

* Audit technique du site et de n’importe quel domaine externe, avec score pondéré 0-100
* Données structurées JSON-LD (Organization, LocalBusiness, WebSite, Article, BreadcrumbList)
* GEO/AEO : llms.txt, llms-full.txt, ai-catalog.json, règles robots.txt pour 12 agents IA
* Signaux E-E-A-T : encart auteur, sameAs, dates de mise à jour
* Rapports exportables en CSV et JSON, audit automatique hebdomadaire

Compatible Rank Math (pas de doublon de Schema en mode auto).

== Installation ==

1. Téléverser le ZIP via Extensions > Ajouter, ou copier le dossier dans wp-content/plugins.
2. Activer l’extension.
3. Renseigner CLOUX SEO > Réglages (identité, sameAs, agents IA).
